QuickSearch 사내 시험 배포 0.1.0 (Windows x64)

Windows 10/11 x64 및 로컬 NTFS 드라이브용입니다.
서비스 설치/제거에 관리자 권한이 필요합니다. 한 PC의 지정된 Windows 사용자 한 명을 지원합니다.
설치 화면에서 실제 사용할 Windows 계정을 확인하세요. 별도 IT 관리자 계정으로 UAC를 승인했다면
기본 계정을 실제 사용자의 DOMAIN\user 또는 PC\user로 수정해야 합니다.
검색 서비스는 부팅 시, 웹 서버는 지정 사용자 로그인 10초 후 자동 실행됩니다.
웹 서버는 일반 권한으로 백그라운드 실행되며 브라우저를 자동으로 열지 않습니다.
설치 후 실제 사용자의 바탕화면/시작 메뉴에서 QuickSearch를 일반 권한으로 실행하세요.
브라우저에서 http://127.0.0.1:8765 가 열립니다. Python이나 Node를 따로 설치할 필요가 없습니다.

기본 파일 검색/로컬 자연어 해석은 API 키 없이 동작합니다.
클라우드 자연어 해석은 사용자가 직접 API 키를 설정할 때만 호출됩니다.
문서 본문과 파일 목록은 LLM에 보내지 않으며 검색 문장과 조건 정의만 전송합니다.
회사에서 허용하는 외부 AI API인지 확인한 후 사용하세요.
API 키, 개인 파일, 개발 PC의 색인/설정은 설치 파일에 포함하지 않습니다.

본문/촬영일 색인은 최초 수집 시간이 필요합니다. 스캔 문서 OCR은 포함하지 않습니다.
공간 현황은 드라이브를 선택하면 최초 용량 분석을 자동으로 시작합니다.
분석이 완료되면 가장 큰 파일과 파일 형식별 사용량이 표시됩니다.
중복 파일 비교는 공간 현황의 중복 검사를 별도로 실행하세요.
일부 문서 형식은 해당 PC에 설치된 Windows IFilter에 따라 지원 여부가 달라집니다.
USN Journal이 꺼진 드라이브는 자동으로 켜지 않으며 상태에 오류를 표시합니다.

제거는 Windows 설치된 앱의 QuickSearch Pilot에서 실행하세요.
제거 시 설치된 프로그램/서비스를 제거하지만 사용자 설정, 암호화한 API 키와 색인은 보존합니다.
API 키는 제거 전에 웹 화면의 '저장된 키 삭제'를 이용해 제거할 수 있습니다.

이 설치 파일은 코드 서명되지 않은 사내 시험판입니다.
배포 담당자는 제공된 SHA-256과 파일을 확인하고 별도 시험 PC에서 설치/검색/제거를 검증하세요.
