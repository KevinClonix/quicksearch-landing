AI에는 검색 문장과 조건 정의를 전송합니다. 파일 원본과 목록은 전송하지 않습니다. 외부 API 사용은 회사 정책과 제공업체의 요금·한도를 확인하세요.

GOOD TO KNOW

시작하기 전에
알아두세요.

지금은 사내 시험 배포 단계입니다.
지원 범위와 사용 조건을 확인해 주세요.

내 파일이 외부 서버에 업로드되나요?+

파일 검색과 색인은 내 PC에서 수행합니다. 클라우드 자연어 해석을 선택하면 검색 문장과 검색 조건 정의를 외부 AI 서비스에 전송하지만, 파일 원본이나 검색 결과 목록은 전송하지 않습니다.

API 키 없이도 사용할 수 있나요?+

네. 파일명·내용·고급 검색과 기본 규칙 기반 자연어 해석은 API 키 없이 사용할 수 있습니다. 자유로운 표현을 AI로 해석할 때만 OpenRouter 또는 OpenAI 키가 필요합니다.

첫 검색에 시간이 걸리거나 결과가 적어요.+

최초 파일 목록·본문·촬영일 색인을 만드는 동안에는 수집된 범위의 결과가 먼저 표시됩니다. 드라이브 선택과 화면의 색인 상태를 확인해 주세요. 본문 검색은 단어·구절 포함 방식이며, 스캔 이미지 OCR은 포함하지 않습니다.

OneDrive와 네트워크 드라이브도 검색하나요?+

현재 시험판은 로컬 NTFS 드라이브를 대상으로 합니다. OneDrive 온라인 전용 파일과 일부 동기화 파일은 누락될 수 있으며, 전용 지원은 아직 적용되지 않았습니다. 네트워크 드라이브는 지원하지 않습니다.

설치 시 무엇을 확인해야 하나요?+

설치에는 관리자 권한이 필요하지만, 프로그램은 실제 사용자의 일반 권한으로 실행해야 합니다. IT 관리자 계정으로 설치를 승인했다면 설치 화면의 사용자 계정을 실제 사용자로 지정하세요. 현재 설치 파일은 코드 서명되지 않은 시험판이며 별도 시험 PC의 설치·제거 검증이 필요합니다.

프로그램을 삭제하면 API 키와 색인도 삭제되나요?+

Windows의 설치된 앱에서 QuickSearch Pilot을 제거하면 프로그램과 서비스를 삭제하고, 사용자 설정·암호화 키·색인은 보존합니다. 키까지 제거하려면 프로그램을 제거하기 전에 화면의 ‘저장된 키 삭제’를 누르세요.
