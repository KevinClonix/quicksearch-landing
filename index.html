r4에 추가된 변화

GOOD TO KNOW

시작하기 전에.

지원 범위와 데이터 처리 방식을
확인해 주세요.

내 파일이 외부로 전송되나요?+

파일 검색과 분석은 내 PC에서 수행합니다. 클라우드 자연어 해석을 선택하면 검색 문장과 조건 정의를 해당 AI 서비스에 전송하지만, 파일 원본과 검색 결과 목록은 보내지 않습니다. 기본 파일 검색과 로컬 규칙 기반 해석은 API 키 없이 사용할 수 있습니다.

100MB는 프로그램 전체 용량인가요?+

내용 검색 캐시의 사용자별·드라이브별 상한입니다. 프로그램 설치 파일, 파일명 색인, 촬영일 등 메타데이터와 다른 기능의 캐시는 별도입니다. 캐시가 가득 차도 파일을 검색 대상에서 제외하지 않고 원본을 읽어 검색합니다.

기존에 커진 내용 검색 DB는 어떻게 되나요?+

r4로 업데이트한 뒤 해당 드라이브의 내용 검색 프로세스가 시작되면 기존 폴더·확장자 설정을 유지하며 대용량 본문 DB를 새 캐시로 교체합니다. 원본 문서는 바꾸지 않습니다. 전환이 완료된 이후 100MB 상한이 적용됩니다.

검색이 오래 걸리거나 일부 결과만 보여요.+

첫 파일 목록·촬영일 수집이나 문서 본문 읽기에는 시간이 필요합니다. 내용 검색은 진행 중 찾은 결과부터 표시하며, 캐시에 없는 PDF·Office·한글 문서는 다시 읽습니다. 드라이브와 파일 형식을 좁히고 진행 상태를 확인하세요. 암호화·손상 문서나 일부 형식은 읽지 못할 수 있으며, 스캔 이미지 OCR은 포함하지 않습니다.

정리 도우미가 파일을 자동으로 삭제하나요?+

자동 삭제하지 않습니다. 후보를 검토하고 선택한 일반 파일에 대해 확인 후 휴지통 이동을 요청합니다. 중복 파일도 자동 삭제하지 않으며, 표시된 후보 용량이 실제 확보 용량을 보장하지는 않습니다. Windows가 휴지통을 사용할 수 없다고 안내하면 영구 삭제를 원하지 않을 경우 취소하세요.

어떤 Windows와 드라이브를 지원하나요?+

Windows 10/11 x64와 로컬 NTFS 드라이브를 기본으로 지원합니다. NTFS 검색에는 활성 USN Journal이 필요하며, 비활성 상태에서는 오류 1179가 표시될 수 있습니다. 프로그램이 Journal을 자동으로 생성하지는 않습니다. FAT32·exFAT는 환경 설정에서 허용할 수 있으며 NTFS와 수집 방식·지원 범위가 다릅니다. 네트워크 드라이브와 OneDrive는 완전 지원하지 않습니다. 특히 온라인 전용 파일은 로컬 파일처럼 검색·분석되지 않을 수 있습니다.

삭제하면 캐시와 API 키도 지워지나요?+

프로그램 제거 시 서비스·실행 파일·업데이트 백업·검색 색인과 분석 캐시를 정리합니다. API 키와 파일 형식 설정도 삭제할지 선택할 수 있으며 기본값은 설정 유지입니다. 원본 파일과 다른 사용자의 데이터는 보존합니다. 브라우저 화면 설정은 브라우저의 사이트 데이터에서 별도로 삭제할 수 있습니다.
